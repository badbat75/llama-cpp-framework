System view

Private AI Framework, target architecture: every design accepted in ARCHITECTURE.md drawn as the system, with a short "Built today" note under each figure and a status column in the tables. The crates and binaries, the manager's API, the bff's routes, and how sign-in, a profile save and a start or stop travel through them. Source: ARCHITECTURE.md, AGENTS.md, crates/bff/README.md and the code, 2026-11-22. When this page and those disagree, they win.

Components

The manager's API

One request, one reply, on D-Bus (org.privateai.Manager1) or the named pipe (u32 length, JSON, 1 MiB), and across machines on the node listener under mutual TLS, unchanged; the caller is the OS identity of the connection. A <Method>As form names a signed-in user; the manager answers it only to the bff's account and only for a current member of pai, re-checked at each call.

The bff's routes

Only /, /assets/* and the three session routes answer without a session; every other route is 401 session-required without one. Errors are {key, args}. In hub mode every instance and profile route is served under /api/nodes/{node}/, same bodies and errors.
