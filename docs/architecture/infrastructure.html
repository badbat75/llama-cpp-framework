Planned on a node

  • The manager without root or LocalSystem (accepted 2026-11-22, slices P1 to P6 at the head of step 14): the manager runs as private-ai-manager (Windows: NT SERVICE\private-ai-manager); a small privileged helper, pai-manager helper, keeps the verbs that cannot be scoped (Linux: the password check, boot on/off, director on/off; Windows: creating, repairing and deleting instance services, boot on/off).
  • Step 15 (planned, last): a minimal install image with only the manager, which then installs the engines; a Docker image is kept pending.
  • 13c Strata: a second engine, its own run config and profile written and launched by the manager beside the llama.cpp instances.
  • 13d monitoring (proposed): a sampler thread in the manager with a fixed-size history store, streamed to the web UI through the bff; logs read on demand from the journal or the log files, for pai members only.
